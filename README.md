# Eska · Mi Entreno

App web instalable (PWA) para el entreno de fuerza y cardio adaptado a la fase del ciclo menstrual.

- Se instala en el iPhone desde Safari, Chrome o Brave: Compartir → Añadir a pantalla de inicio.
- Funciona sin conexión. Los datos se guardan solo en el dispositivo (Ajustes → Exportar / Importar copia).
- Publicada con GitHub Pages desde la rama `main` (raíz).

## Mi Armario (`/armario/`)

Armario digital: fotos de cada prenda y todas las combinaciones posibles. App independiente (su propio icono, sus datos y su caché), en `mavi-meerkat.github.io/eska/armario/`.
